# Yadava H C — Portfolio

A premium, dark-themed personal portfolio for **Yadava H C** — Full Stack Developer & AI Builder.

Built with **Next.js 14**, **TypeScript**, **Tailwind CSS**, **Three.js / React Three Fiber**, **Framer Motion**, and **Lenis** smooth scroll. Black backgrounds, white text, silver/metallic accents, immersive 3D hero, parallax, and a unique animation per section.

## Sections
Hero (3D + mouse parallax) · About & Education · Technical Skills · Projects · Experience · Achievements · DSA Roadmap · Certificates · Volunteering · Contact.

## Getting started

```bash
npm install
npm run dev      # http://localhost:3000
npm run build    # production build
npm start        # serve production build
```

## Tech stack
- Next.js 14 (App Router) + TypeScript
- Tailwind CSS
- Three.js · @react-three/fiber · @react-three/drei
- Framer Motion
- Lenis (smooth scrolling)
- react-icons
